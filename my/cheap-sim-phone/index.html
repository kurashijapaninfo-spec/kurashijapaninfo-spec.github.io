ဂျပန် ဆင်းကတ် လုပ်နည်း ၂၀၂၆ – ID စစ်ဆေးမှု စည်းမျဉ်းသစ်

အတိုချုပ် (၃ ချက်) ၁။ ဂျပန်မှာ ဆင်းကတ်လုပ်ရင် ID စစ်ဆေးမှုကို ဥပဒေက မဖြစ်မနေ လုပ်ခိုင်းထားပါတယ်။ အွန်လိုင်းမှာ စာချုပ်ချုပ်ရင် ၂၀၂၆ ဧပြီ ၁ ရက်ကစပြီး ID ကတ်ရဲ့ IC ချစ်ပ်ကို ဖတ်ရပါမယ်။ ၂။ ဆိုင်မှာ သွားလုပ်ရင်လည်း ၂၀၂၇ ဧပြီနောက်ပိုင်းမှာ IC ချစ်ပ်ဖတ်ဖို့ လိုလာပါမယ်။ ၃။ ကိုယ့်နာမည်နဲ့ လုပ်ထားတဲ့ ဖုန်း/ဆင်းကတ်ကို တခြားသူကို ရောင်းတာ၊ ပေးတာ ပြစ်မှုဖြစ်နိုင်ပါတယ်။

📝 လျှောက်လွှာစာမျက်နှာက ဂျပန်ဘာသာလား? အကွက်တစ်ခုချင်း ဖြည့်နည်း ကြည့်ရန်

ဂျပန်မှာ အလုပ်လုပ်ဖို့၊ မိသားစုနဲ့ ဆက်သွယ်ဖို့ ဖုန်းက မရှိမဖြစ်ပါ။ ဒီဆောင်းပါးမှာ ဂျပန် ဆင်းကတ် လုပ်နည်းကို အဆင့်လိုက် ရိုးရိုးရှင်းရှင်း ရှင်းပြပေးပါမယ်။ ID စည်းမျဉ်းအသစ်၊ ဈေးပေါတဲ့ ဆင်းကတ် (格安かくやすSIM / kakuyasu sim) သုံးရင် သတိထားရမယ့်အချက်တွေ၊ ပြဿနာမဖြစ်အောင် ကိုယ့်ကိုယ်ကို ကာကွယ်နည်းတွေ ပါပါတယ်။

ဘာကြောင့် ID စစ်ဆေးမှု တင်းကျပ်လာတာလဲ

ဂျပန်မှာ "ဖုန်းမသမာမှု တားဆီးရေးဥပဒေ" (携帯けいたい電話でんわ不正ふせい利用りよう防止ぼうし法ほう) ရှိပါတယ်။ အရင်က သူများနာမည်နဲ့ လုပ်ထားတဲ့ ဖုန်းတွေကို လိမ်လည်မှု (特殊とくしゅ詐欺さぎ) မှာ သုံးခဲ့ကြလို့ ဒီဥပဒေကို ပြဋ္ဌာန်းခဲ့တာပါ။ ဒါကြောင့် ဖုန်းကုမ္ပဏီတွေက စာချုပ်ချုပ်တဲ့အခါ ID စစ်ဆေးရပါတယ်။

အခု ပြောင်းလဲမှုတွေကတော့ ဒီလိုပါ –

  • အွန်လိုင်း စာချုပ် – ၂၀၂၆ ဧပြီ ၁ ရက်ကစပြီး IC ချစ်ပ် ဖတ်တာ အခြေခံအားဖြင့် မဖြစ်မနေ လိုပါပြီ။
  • ဆိုင်မှာ စာချုပ် – ၂၀၂၇ ဧပြီ နောက်ပိုင်းမှာ IC ချစ်ပ် ဖတ်တာ မဖြစ်မနေ လိုလာပါမယ်။
  • ဒေတာသီးသန့် ဆင်းကတ် (データ専用せんようSIM) – အရင်က ID စစ်ဆေးမှု မလိုခဲ့ပေမဲ့ ၂၀၂၆ မေလမှာ ထုတ်ပြန်တဲ့ ပြင်ဆင်ဥပဒေအရ ID စစ်ဆေးမှု လိုလာပါမယ်။ စတင်ကျင့်သုံးမယ့်ရက်ကို ထုတ်ပြန်ပြီး ၁ နှစ်အတွင်း အစိုးရအမိန့် (政令せいれい) နဲ့ သတ်မှတ်ပါမယ်။ ပြည်ထဲရေးနဲ့ ဆက်သွယ်ရေးဝန်ကြီးဌာန (総務そうむ省しょう) စာမျက်နှာမှာ "၂၀၂၇ ဧပြီ နောက်ပိုင်း" လို့ ရေးထားပေမဲ့ တိကျတဲ့ရက်ကို မအတည်ပြုရသေးပါ။ တရားဝင်ရုံးမှာ ထပ်စစ်ပါ။

အောက်ပါနည်းလမ်းတွေကိုလည်း အခြေခံအားဖြင့် ဖျက်သိမ်းပါမယ် – - ID ကတ်ရဲ့ ဓာတ်ပုံကို upload တင်တဲ့နည်း - ID မိတ္တူကို စာတိုက်ကနေ ပို့တဲ့နည်း - ကိုယ့်ဓာတ်ပုံမပါတဲ့ စာရွက် (IC ချစ်ပ်လည်း မပါ၊ အတုလုပ်ခြင်း ကာကွယ်ရေး အစီအမံလည်း မပါတဲ့ စာရွက်) ကို သုံးတဲ့နည်း

အဆင့် ၁ – ID စာရွက်စာတမ်း ပြင်ဆင်ပါ

総務そうむ省しょう စာရွက်စာတမ်းမှာ ID အဖြစ် သုံးနိုင်တာတွေကို ဒီလို ဖော်ပြထားပါတယ် – - နေထိုင်ခွင့်ကတ် (在留ざいりゅうカード / zairyu card) - ပတ်စ်ပို့ - My Number ကတ် (マイナンバーカード) - ယာဉ်မောင်းလိုင်စင် (運転うんてん免許めんきょ証しょう) - အထူးအမြဲနေထိုင်သူ အသိအမှတ်ပြုလက်မှတ် (特別とくべつ永住えいじゅう者しゃ証明しょうめい書しょ)

အရေးကြီး – 総務そうむ省しょう စာမျက်နှာမှာ IC ချစ်ပ်ပါတဲ့ ID ဥပမာအဖြစ် My Number ကတ်နဲ့ ယာဉ်မောင်းလိုင်စင်ကိုပဲ ဖော်ပြထားပါတယ်။ နေထိုင်ခွင့်ကတ် ဒါမှမဟုတ် ပတ်စ်ပို့ရဲ့ IC ချစ်ပ်ဖတ်တာနဲ့ လုံလောက်သလားဆိုတာ မအတည်ပြုရသေးပါ။ ဖုန်းကုမ္ပဏီ ဒါမှမဟုတ် တရားဝင်ရုံးမှာ မေးမြန်းပါ။

လျှို့ဝှက်နံပါတ် (暗証あんしょう番号ばんごう / anshō bangō) – IC ချစ်ပ်ဖတ်တဲ့အခါ လျှို့ဝှက်နံပါတ် လိုနိုင်ပါတယ်။ မေ့သွားရင် အဲဒီကတ်ကို ထုတ်ပေးတဲ့ အစိုးရရုံးမှာ မေးမြန်းနိုင်ပါတယ်၊ အသစ်ပြန်သတ်မှတ်နိုင်ပါတယ်။ စာချုပ်မချုပ်ခင် ကြိုစစ်ထားပါ။

IC ချစ်ပ်ပါတဲ့ ID မရှိရင် – နေထိုင်ရာ မှတ်ပုံတင်မိတ္တူ (住民じゅうみん票ひょうの写うつし / jūminhyō no utsushi) လို တခြားစာရွက်နဲ့ စစ်ဆေးနိုင်ပါတယ်။ အဲဒီအခါ ဖုန်းကုမ္ပဏီက မှတ်ပုံတင်စာ (書留かきとめ / kakitome) စသည်ဖြင့် ပို့ပါလိမ့်မယ်။ မဖြစ်မနေ လက်ခံယူရပါမယ်။

အဆင့် ၂ – ဖုန်းက သုံးလို့ရမလား စစ်ပါ

  • SIM Lock ရှိမရှိ စစ်ပါ။ SIM Lock ဖြုတ်မထားရင် တခြားကုမ္ပဏီရဲ့ ဆင်းကတ်ကို သုံးလို့မရပါ။
  • တစ်ပတ်ရစ်ဖုန်းဆိုရင် "ကွန်ယက်အသုံးပြုမှု ကန့်သတ်ချက်" (ネットワーク利用りよう制限せいげん) ရှိမရှိ စစ်ပါ။ ဖုန်းဖိုး မပေးရသေးတဲ့ တစ်ပတ်ရစ်ဖုန်းကြောင့် ပြင်ပေးဖို့ ငြင်းခံရတဲ့ ဖြစ်ရပ်တွေ ရှိခဲ့ပါတယ်။

အဆင့် ၃ – ဈေးပေါတဲ့ ဆင်းကတ် (kakuyasu sim) ဆိုရင် ဝန်ဆောင်မှုကို သေချာဖတ်ပါ

ဈေးပေါတဲ့ ဖုန်းကုမ္ပဏီ (MVNO) တွေက ဈေးသက်သာပေမဲ့ စားသုံးသူ ဗဟိုဌာန (国民こくみん生活せいかつセンター) က ၂၀၁၇ ခုနှစ်မှာ ပြဿနာဖြစ်ရပ်တွေကို ထုတ်ပြန်ခဲ့ပါတယ် – - ဖုန်းနဲ့ပဲ မေးလို့ရပြီး ဖုန်းဆက်လို့ မရလွယ် - ဖုန်းပြင်နေချိန် အစားထိုးဖုန်း မငှားပေး - အီးမေးလ်လိပ်စာ မရ - ပို့ပြီး ရက်အနည်းငယ်အတွင်း အသုံးပြုချိန် စတင်တာကို မသိခဲ့

ဒါကြောင့် စာမချုပ်ခင် ဒါတွေကို စစ်ပါ – မေးမြန်းရေးနည်းလမ်း၊ အီးမေးလ်ရ/မရ၊ ပြင်နေချိန် အစားထိုးဖုန်း၊ အသုံးပြုမှု စတင်ရက်။

အဆင့် ၄ – စာချုပ်ချုပ်ပါ

  • အွန်လိုင်းမှာ စာချုပ်ရင် IC ချစ်ပ်ဖတ်ရပါမယ်။
  • IC ချစ်ပ်မပါတဲ့ စာရွက်နဲ့ စစ်ဆေးခဲ့ရင် ဖုန်းကုမ္ပဏီက ပို့တဲ့ မှတ်ပုံတင်စာကို လက်ခံယူပါ။
  • ငွေပေးချေနည်း – ခရက်ဒစ်ကတ်မရှိဘဲ ပေးလို့ရတဲ့နည်း (ဘဏ်ကနေ အလိုအလျောက်ဖြတ်တာ၊ debit ကတ် စသည်) ကို တရားဝင်အဖွဲ့အစည်းတွေရဲ့ အချက်အလက်မှာ မတွေ့ရပါ (မအတည်ပြုရသေး)။ စာမချုပ်ခင် ဖုန်းကုမ္ပဏီကို တိုက်ရိုက်မေးပါ။

သတိ – လက်ရှိသုံးနေတဲ့ ဖုန်းလိုင်းအတွက်လည်း ID စစ်ဆေးမှု မပြီးရင် ကုမ္ပဏီက ဝန်ဆောင်မှု ရပ်နိုင်ပါတယ်။ လူတစ်ယောက် စာချုပ်လို့ရတဲ့ လိုင်းအရေအတွက်ကိုလည်း ကန့်သတ်နိုင်ပါတယ်။

အဆင့် ၅ – စာချုပ်ဖျက်တဲ့အခါ၊ မြန်မာပြည်ပြန်တဲ့အခါ

  • ဖုန်းလိုင်း ဒါမှမဟုတ် ဆင်းကတ်ကို သူငယ်ချင်း၊ ပွဲစားကို မပေးပါနဲ့၊ မရောင်းပါနဲ့။ ဖုန်းကုမ္ပဏီမှာ စာချုပ်ဖျက်ပါ၊ ဒါမှမဟုတ် တရားဝင် နာမည်ပြောင်းပါ။
  • ပြန်ခါနီး စာချုပ်ဖျက်နည်းကို တရားဝင်အချက်အလက်မှာ မအတည်ပြုရသေးလို့ ကိုယ့်ဖုန်းကုမ္ပဏီမှာ စောစော မေးထားပါ။
  • စာချုပ်ဖျက်ခ – ၂၀၂၂ ခုနှစ် စည်းမျဉ်းပြင်ဆင်မှုအရ စာချုပ်ဖျက်တဲ့အခါ လိုအပ်တာထက်ပိုပြီး တောင်းခံတာကို တားမြစ်ထားပါတယ်။ 総務そうむ省しょう စာရွက်မှာ "စာချုပ်ကာလ ချည်နှောင်မှု ဒဏ်ကြေးက တစ်လစာ ကြေးနဲ့ ညီမျှတဲ့ပမာဏ" ဆိုတဲ့ ဥပမာ ပါပါတယ်။ စာချုပ်ဟောင်းတွေအတွက် ခြွင်းချက်တွေကို တဖြည်းဖြည်း ဖျက်ပြီး ၂၀၂၈ ဇွန်လကုန်မှာ လုံးဝဖျက်ဖို့ စီစဉ်ထားပါတယ် (၂၀၂၄ စာရွက်အရ)။ ကိုယ့်စာချုပ်အကြောင်း ကုမ္ပဏီကို မေးပါ။

နာမည်ငှားခြင်း (名義めいぎ貸かし / meigi gashi) – ပြစ်ဒဏ်တွေ

ဥပဒေ ပုဒ်မ ၇ အရ ကိုယ့်နာမည်နဲ့ လုပ်ထားတဲ့ ဖုန်း/ဆင်းကတ်ကို ဆွေမျိုး ဒါမှမဟုတ် အိမ်ထောင်စုတူ လူကလွဲပြီး တခြားသူကို ပေးရင် ဖုန်းကုမ္ပဏီရဲ့ ခွင့်ပြုချက်ကို ကြိုယူရပါမယ်။

လုပ်ရပ် ပြစ်ဒဏ်
ခွင့်ပြုချက်မရှိဘဲ စီးပွားဖြစ် ငွေယူပြီး ပေးခြင်း ထောင် ၂ နှစ်အထိ ဒါမှမဟုတ် ယန်း ၃ သန်းအထိ ဒဏ်ငွေ (နှစ်ခုလုံးလည်း ချနိုင်)
ကိုယ့်နာမည်မဟုတ်တဲ့ ဖုန်းကို ပေးခြင်း/လက်ခံခြင်း ယန်း ၅၀ သောင်းအထိ ဒဏ်ငွေ
ကိုယ်ဘယ်သူလဲဆိုတာ ဖုံးကွယ်ဖို့ ရည်ရွယ်ပြီး ID စစ်ဆေးချိန် လိမ်ညာခြင်း ယန်း ၅၀ သောင်းအထိ ဒဏ်ငွေ
ဒီလုပ်ရပ်တွေကို ဖိတ်ခေါ်ခြင်း၊ ကြော်ငြာခြင်း ယန်း ၅၀ သောင်းအထိ ဒဏ်ငွေ
  • "ဖုန်းစာချုပ်ချုပ်ပေးရုံနဲ့ ပိုက်ဆံရမယ်" ဆိုတဲ့ အချိန်ပိုင်းအလုပ်မျိုးဟာ ဆိုင်ကို လိမ်လည်မှု (詐欺さぎ罪ざい) ဖြစ်နိုင်တယ်လို့ တိုကျိုရဲ (警視けいし庁ちょう) က ပြောပါတယ်။ ပိုက်ဆံရခဲ့ရင်တောင် ဖုန်းဖိုး၊ လစဉ်ကြေး ပေးရမယ့်တာဝန်က ကိုယ့်ဆီမှာပဲ ကျန်ပါတယ်။
  • "ဖုန်း/ဆင်းကတ် ကိုယ့်အစား စာချုပ်ပြီး ပို့ပေးပါ" လို့ တောင်းဆိုတာမျိုးကို သတိထားဖို့ 総務そうむ省しょう က သတိပေးပါတယ်။
  • မိယာဂီခရိုင်ရဲ (宮城県けん警けい) ကလည်း ဂျပန်မှာနေတဲ့ နိုင်ငံခြားသားတွေကို ဖုန်း ဒါမှမဟုတ် ဘဏ်အကောင့်ကို တခြားသူကို ပေးရင် ပြစ်မှုဖြစ်ကြောင်း၊ SNS စတာတွေကနေ ခေါ်တာမျိုးကို လိုက်မလုပ်ဖို့ သတိပေးထားပါတယ်။

မေးလေ့ရှိသော မေးခွန်းများ (FAQ)

မေး – နေထိုင်ခွင့်ကတ်နဲ့ အွန်လိုင်းမှာ ဆင်းကတ် လုပ်လို့ရလား? ဖြေ – နေထိုင်ခွင့်ကတ်ကို ID အဖြစ် ဖော်ပြထားပါတယ်။ ဒါပေမဲ့ IC ချစ်ပ်ဖတ်တာနဲ့ လုံလောက်သလားဆိုတာ မအတည်ပြုရသေးပါ။ ဖုန်းကုမ္ပဏီကို မေးပါ။

မေး – ခရက်ဒစ်ကတ် မရှိရင် ဘယ်လိုပေးရမလဲ? ဖြေ – တရားဝင်အချက်အလက် မတွေ့ရသေးပါ။ ဖုန်းကုမ္ပဏီကို တိုက်ရိုက်မေးပါ။

မေး – မြန်မာပြည်ပြန်ခါနီး ဆင်းကတ်ကို သူငယ်ချင်းကို ရောင်းလို့ရလား? ဖြေ – မရောင်းပါနဲ့။ ကုမ္ပဏီခွင့်ပြုချက်မရှိဘဲ ပေးတာ ဥပဒေချိုးဖောက်ရာ ရောက်နိုင်ပါတယ်။ စီးပွားဖြစ် ငွေယူပြီး လုပ်ရင် ထောင် ၂ နှစ်အထိ ဒါမှမဟုတ် ယန်း ၃ သန်းအထိ ဒဏ်ငွေ ကျနိုင်ပါတယ်။ ကုမ္ပဏီမှာ စာချုပ်ဖျက်ပါ။

မေး – အခုသုံးနေတဲ့ ဖုန်းလိုင်းကိုရော အသစ်ပြန်စစ်မလား? ဖြေ – ID စစ်ဆေးမှု မပြီးရင် ကုမ္ပဏီက ဝန်ဆောင်မှု ရပ်နိုင်ပါတယ်။ ကုမ္ပဏီက ဆက်သွယ်လာရင် အမြန်ဆုံး လုပ်ဆောင်ပါ။

မေး – ဒေတာသီးသန့် ဆင်းကတ်ကိုရော ID လိုလား? ဖြေ – ပြင်ဆင်ဥပဒေအရ လိုလာပါမယ်။ စတင်ရက်ကို မအတည်ပြုရသေးလို့ 総務そうむ省しょう စာမျက်နှာမှာ စစ်ပါ။

သတိပြုရန် – ဒီဆောင်းပါးဟာ ယေဘုယျ အချက်အလက်သာ ဖြစ်ပြီး ဥပဒေအကြံဉာဏ် မဟုတ်ပါ။ စည်းမျဉ်းတွေ ပြောင်းလဲနိုင်လို့ တရားဝင်ရုံး ဒါမှမဟုတ် ဖုန်းကုမ္ပဏီမှာ နောက်ဆုံးအခြေအနေကို အမြဲစစ်ပါ။ (၂၀၂၆ နိုဝင်ဘာ ၂၅ ရက်နေ့ အချက်အလက်အရ)
